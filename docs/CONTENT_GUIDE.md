# 内容管理指南

后台入口为 `/#/admin`（history 路由为 `/admin`），只有本地初始化的唯一站主可登录。初始化命令 `npm run owner:init`；密码至少 12 位，输入不回显。登录会话 12 小时，写入操作校验同源和 CSRF。修改密码会撤销全部会话及 CLI Token，重新登录后签发新 Token。

音乐、文章、图库和足迹使用独立的紧凑表格页。先搜索/筛选，点击行或名称查看只读详情，点击「编辑内容」才进入编辑器；返回列表时会保护未保存修改，上传/保存期间不能离开。足迹页内切换「已去 / 未来」。Visible 为公开开关，Status 为文章草稿/发布状态，Order 为排序，Source URL 为媒体地址，Coordinates 为高德经纬度。

## 素材库

「素材库」统一查看上传的 Logo、图片、音频和 PDF，支持缩略图/列表切换、文件名搜索、用途筛选与分页。上传用途默认 Logo，支持 PNG/JPG/WebP/SVG；点击素材查看预览、尺寸、大小、地址，复制或下载。上传不等于公开，保存到公开内容后才按引用规则开放。

内容编辑器每个上传入口旁有「选择素材」，可复用兼容的已上传文件；Purpose 可切到 All 扩大选择范围。品牌 Logo 的标签、单色/比例仍在「Logo 库」管理。删除素材先检查引用，不会删除仍被使用的文件。

## 界面与个人资料

「界面与控件」与「个人资料」已合并为「我 · 可视化编辑」（`/#/admin/me`），旧入口仍可使用。左侧显示真实网页；单击文字、图片或经历条目，右侧只显示对应设置。双击文字可直接输入：单行按 Enter 完成，多行按 Ctrl/⌘+Enter 完成，Esc 取消，也可点击外部完成。头像和 Logo 可上传或从素材库替换。导航、外观、播放器和隐藏模块从右侧快捷设置打开。「更多设置」包含全部文案、图标和网站设置。

修改首先显示在本人的预览里，点击「保存到网站」后才公开。两类资源共享一个保存按钮，保存前校验全部改动；部分失败时，已成功的版本会保留，未成功的修改仍可继续保存。可以撤销未保存修改；离开时会提示。正在直接输入文字或上传时请先完成当前操作。小游戏和像素动画不参与编辑。

「个人资料」编辑头像、简介、联系方式、教育/经历/项目、技能和认证，支持增删和排序数组项。「Logo 库」上传图形、设置标签/比例/单色显示，随后在资料条目选择 Logo。可给经历添加/移除文字徽标。小游戏与像素画保留原有实现。

排序只影响相应列：经历/项目/教育在主列，技能/认证在侧列；两列布局保持原网站机制。访客自选主题、播放模式、音量、歌单顺序继续保存在浏览器，不会被站主保存默认设置时强制覆盖。

## 照片

在「图库」新建并上传，或批量上传后逐项填写。上传会生成去除 EXIF 的 WebP 和缩略图；原始文件只有管理登录/媒体读取权限 Token 可下载。

自动读拍摄日期与 GPS；有 GPS 时先把 WGS84 转为高德 GCJ-02，再查地址。没有 GPS 或地点查询失败仍可上传。不要推测不存在的坐标：使用高德地点搜索，查看候选名称/地址后选择，也可手动输入坐标。日期接受 `YYYY-MM` 或 `YYYY-MM-DD`。填写标题、地点、照片文案，选择关联的已去足迹。双向照片关系会同步更新。

单张新建默认公开；批量上传默认不公开，填完文案再打开 Visible。隐藏照片仍可在后台关联选择。最大 40 MB，像素限制 6000 万；支持由当前 Sharp 构建识别的 JPG/PNG/WebP/GIF/AVIF/TIFF/HEIF，具体格式以上传反馈为准；多帧只使用第一帧。SVG 只用于经过校验的 Logo，公开为静态 WebP。

## 音乐

在「音乐」新建并上传音频，可填标题、艺术家、专辑、备注和封面，也可批量导入未公开记录。支持 MP3、MP4/M4A、AAC、OGG、FLAC、WAV（检查内容标识和扩展名）；上限 100 MB，流式暂存，断开/超限会清理。播放器支持 Range，请保留上传返回的 `variants.original` 地址。

MP4 由服务端 FFmpeg 提取第一条音轨为 MP3（192 kbps、44.1 kHz、双声道），不保留视频、字幕、原 metadata 或上传的 MP4 文件；返回文件名为 `.mp3`，文件大小/摘要以转换后的音频为准。没有音轨、文件损坏、超过输出 100 MB 或转换 120 秒上限会明确失败并清理临时文件；同时最多转换两项，繁忙时稍后重试。MP3 与已有音频格式继续使用原来的上传流程。CLI 上传 MP4 也遵循相同规则。

调整后台顺序后公开播放列表同步，正在播放的同一文件继续播放。删除当前曲目会停止它。先删除内容引用，再在「素材库」清理不再使用的文件。

## 文章

路径示例 `知识/模型评估`，路径的父目录就是分类；显示标题独立于路径。填日期、摘要、标签、封面、推荐状态与 Markdown 正文。预览支持图片、行内 `$x$` / 块级 `$$x$$` 公式、表格、代码、Mermaid。图片可用「插入图片」上传，也可使用现有公开图片 URL。正文 HTML/SVG 经过前端安全清洗；script、事件处理器等不会执行。

新文章默认草稿，保存后可继续修改，切换「已发布」再保存才公开。草稿/取消发布的正文，以及仅被该文章引用的托管图片和旧附件，不可匿名访问。「文章分类」设置显示名称和排序；带文章的分类需要先移动文章才能删除。

更新、删除、排序检查记录版本。出现版本冲突时重新加载，结合最新内容再修改；不要用旧版本自动重试覆盖。取消发布不删除内容。文件清理受引用检查保护。

## 足迹

「已去足迹」填名称、地区、高德坐标、日期和记录，可选择多张照片。「未来足迹」填想去原因，地图坐标可选。地点搜索保留全部候选；点卡片时有坐标才能定位地图。

未来足迹已经去过时，先保存地点修改，再填写出行日期和记录，点击「移入已去足迹」。转换在一个数据库事务中完成，任意校验失败仍保留原愿望。删除足迹会解除照片关联而保留照片本身。

## AI 与 CLI

运行 `npm run skill:install` 安装 `personal-site-cms`。在「Token 与账户」签发必要的读/写范围与到期时间，原始令牌只显示一次，妥善保存到本地私密文件。写范围包含对应读取能力。Token 不能签发新 Token 或修改密码。服务端验证所有字段与引用，AI 与后台使用同一业务 API。

CLI 离线 `schema` 可查字段，`convert` 可准备格式，`publish --dry-run` 只转换检查。实际发布需要 `SITE_URL` 和 `SITE_TOKEN` 或 `--token-file`。远程 URL 必须 HTTPS，禁止携带 URL 凭据或跟随重定向。支持 Markdown/Obsidian、HTML、DOCX，保留本地图片相对目录并检查目录越界/符号链接，按内容哈希去重上传。Obsidian 私有 `%% 注释 %%` 去除，代码示例中的注释保留。Word 原生公式不会声称转换准确：报告标记检查，转为 LaTeX Markdown 后发布。

```powershell
node tools/cli/site-cli.mjs schema gallery
node tools/cli/site-cli.mjs convert --file C:/prepared/note.md --out C:/prepared/result --path 随笔/新文章
node tools/cli/site-cli.mjs publish --file C:/prepared/note.md --path 随笔/新文章 --dry-run
node tools/cli/site-cli.mjs publish --file C:/prepared/note.md --path 随笔/新文章 --status published --token-file C:/private/token.txt
```

重复发布同样正文/媒体会复用；修改已存在路径时需先读取最新版本，再传 `--revision N`。冲突前已经成功上传的文件可能留在媒体库，可确认无引用后清理。所有资源 CRUD、排序、愿望转换、地图查询、统计命令见 [完整命令](../tools/skills/personal-site-cms/references/commands.md)。

## 访客与持久化

后台显示 7/30/90 日访问量、每日去重访客、页面、来源主机和设备。跨日访客数是每日人数之和，不是跨日身份去重。只保存匿名每日哈希，不保存原始 IP/完整 UA；关闭追踪的访客、机器人和已登录站主不会计入。无法代表全部真实访客。

内容和媒体保存在 `SITE_DATA_DIR`，重新构建、重启都保留。备份需停止服务和文件变更命令，执行 `npm run backup -- --out 新目录`；恢复到新数据目录并验证后切换配置，保留旧目录可回退。详见 [部署与备份](DEPLOYMENT.md)。
## 照片与足迹的地区关联

图库中每张照片只属于一条足迹，一个地区可以关联多张照片。新建或编辑照片时，在「照片所属地区」选择已有地区；批量上传可以统一选择「批量上传所属地区」。保存后，两端共用同一条关系，足迹详情展示照片缩略图，点击可以进入图库；后台足迹详情也能查看照片。

默认「根据照片地点自动关联」优先匹配同名足迹，再匹配唯一的相同地区或相同坐标。没有匹配时，有有效坐标和地点名称的照片会同时建立足迹；只有地点文字而没有坐标时，需要选择已有足迹或通过地点搜索补充坐标。同名地区有多个候选时需手动选择，系统不会猜测。修改照片地点或重新定位后，保存时会重新关联。

图库列表的「同步已有照片地点」可为旧照片补关联，包含旧版保存的空关联字段；只处理当前未关联的照片，不移动已有关系。重复同步不会创建重复地区。需要补充地点、坐标或选择候选的照片会给出反馈。选择「不关联足迹」可以在日常保存时保持照片独立；手动同步会重新尝试关联所有未关联照片。

公开足迹只展示公开照片。由未公开照片建立的足迹也保持未公开，需要在足迹管理中公开地区。API 自动建立新足迹或同步旧照片需要同时拥有 `gallery:write` 和 `footprints:write`；仅复用已有足迹沿用图库编辑权限。

## 富文本写作与 Markdown 导入

文章列表右上有「新建」和「导入 Markdown」。新建直接打开类似邮件的撰写页：标题、副标题、正文和工具栏，支持粗体、标题、列表、引用、代码、表格、链接及公式。点击「公式」输入 LaTeX，插入后即时渲染，点击已有公式可以修改。剪贴板图片、拖放和工具栏上传均立即调用统一媒体接口，等待服务器返回媒体 URL 后才允许保存文章；正文不保存 base64 或本地磁盘路径。这一接口沿用文件存储适配层，未来更换对象存储时，编辑器无需依赖本地文件布局。

停止输入约 1.6 秒自动保存。新文或未发布文保存为普通草稿，可在列表按「草稿」筛选。已发布文章的编辑保存到独立的工作草稿表，公开正文与新图片保持原来的发布边界；再次打开编辑器会继续工作草稿。点击「发布文章 / 发布更新」才公开。保存失败或发生版本冲突时，当前编辑保留，浏览器当前页签另有恢复副本；离开尚未完成的上传/保存会提示。冲突时可复制正文，再明确舍弃草稿、读取最新版并手动合并。

导入需选择 `.md` / `.markdown` 文件。可以直接修改显示出来的 YAML 头与正文，重新检查标题、路径、日期、标签等。解析结果列出本地图片路径（包括封面和引用式图片），为每个路径选择对应文件；全部就绪后「导入并打开草稿」。远程图片继续使用远程地址，本地图片上传后替换为媒体地址。导入与已有文章默认使用 Markdown 编辑，保留 Mermaid、SVG、代码示例等原文；常规文稿可切换富文本。复杂 Obsidian 附件文件夹、HTML、DOCX 仍推荐通过 CLI 准备与导入。

## 个性鼠标与趣味组件

公开网站顶栏的小图标可选择黄色星星（流星拖尾）、侏儒兔（点击动耳朵、胡萝卜拖尾）、小鹦鹉（点击啄动、无拖尾），也可恢复系统鼠标。选择保存在访客自己的浏览器中。触屏使用原生交互；系统要求减少动态效果时停用拖尾与点击动画。

管理页「我 · 可视化编辑」的快捷设置有「小游戏与像素人 · 显示开关」及「个性鼠标」。小游戏和像素人可独立隐藏，保存后公开页面同步变化；后台鼠标设置控制新访客的默认主题。这里只控制显示与主题，游戏规则、像素画和动画内容仍保留原有结构。公开页页脚的「管理网站」跳到管理台，未登录时显示站主登录页。
