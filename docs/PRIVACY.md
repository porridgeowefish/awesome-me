# 公开数据边界

本项目使用全新 Git 历史，仅提供虚构资料、城市级演示坐标、原创插画、合成提示音和系统使用指南。原作者的履历、联系方式、个人照片、笔记、环境密钥、账号和数据库未进入这份项目。

| 可以提交 | 必须留在本机或服务器 |
| --- | --- |
| 程序源码与测试 | `.env.server`、`.env.local` 与密钥 |
| 空配置模板 | SQLite 数据库、会话和令牌 |
| 虚构示例资料 | 上传原图、草稿、日志、统计与备份 |
| 原创示例插画与文档 | 真实简历、旅行记录、私人笔记与私人照片 |

`npm run check:privacy` 扫描本仓库已跟踪文件与未忽略的待提交文件，拒绝环境文件、数据库、私钥、简历文档和压缩包，检查常见密钥形态、私人邮箱、本机用户目录和图片 EXIF。忽略规则只影响正常 `git add`；已跟踪或强制加入的文件仍会被检查。

这项检查是辅助工具，无法判断所有个人信息，也不会自动删除图片里的脸、门牌或文本。修改示例资料、替换媒体、增加文章后，人工检查将公开的内容，再运行 `npm run check:release`。不要复制私人网站的数据库、上传目录或 Git 历史到这里。

后台生成的公开图片去除 EXIF，但你填写的日期、地点、介绍和正文会公开。原始图片只供站主读取。备份包含账号哈希、草稿与原图，需要私下保存。

公开 GitHub 仓库只提交项目源码。安装依赖、初始化账号和运行网站后产生的目录已经默认忽略。
