# 管理图库、足迹与音乐

## 1. 上传照片

在管理台「图库」上传单张或一组图片。系统会生成压缩图和缩略图，公开派生图移除 EXIF，原图仅站主可读。照片里的脸、门牌或文档内容仍属于图片内容；公开前检查或自行处理。

![示例湖景插画](./assets/lake.webp)

填写标题、日期、地点与文字记录。示例插画没有真实人物和拍摄轨迹，适合先体验图库交互。

## 2. 关联足迹

在「足迹 → 已去」新建地点。配置高德后可搜索地点，也可以手动输入 GCJ-02 坐标。关联图库照片后，公开地图上的点会展示相应照片。

「未来」页签记录想去的地方。真的去了以后，可以将愿望转换为已去足迹。示例坐标只用于展示，不是作者的真实行程。

## 3. 管理音乐

项目自带一段脚本合成的三秒提示音，用于体验播放器。在「音乐」上传你拥有使用权的音频，设置标题、艺术家、封面和排序。MP4 上传会提取音轨，画面不保存；这一步需要 FFmpeg。

播放器会持续播放，切换页面不会重新开始。后台可以关闭播放器，或设置默认音量与播放模式。

## 4. 公开哪些信息

发布内容、缩略图、主动填写的地点和文字对访客可见；草稿、原图、管理账号和令牌属于运行数据。删除 Git 忽略规则不会完成脱敏，上传 GitHub 时只上传经过检查的项目源码。
