# 发布第一篇图文文章

## 用后台写作

登录管理台，进入「文章」，点击「新建」。填写标题、路径、日期、分类和标签，在编辑器输入正文。支持粘贴或拖放图片、插入表格、代码和公式。停止输入后约 1.6 秒会自动保存草稿；完成后点击发布。

编辑已发布的文章时，修改先进入工作草稿。点击「发布更新」才替换公开正文，访客可以继续阅读之前发布的版本。

## 导入 Markdown

在「文章 → 导入 Markdown」选择文件，检查 YAML 头和本地图片，再进入草稿编辑器。下面是最小文章：

```markdown
---
title: 我的第一篇文章
date: 2026-10-04
tags: [生活]
---

# 今天的记录

开始写作，比等待完美更有用。

![我的图片](./assets/photo.webp)
```

`docs/examples/first-post.md` 可以作为离线导入或 CLI 发布的起点。

## 发布前检查

确认文章路径、标题和图片正确，正文不含私人信息。图片文件的 EXIF 会在后台生成公开派生图时移除；文章文字和你主动填写的地点仍会公开，需要自行检查。
